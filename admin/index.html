    No key yet? How to get one
    1. On github.com, tap your picture, then Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
    2. Name it flashgrain admin. Expiration: 90 days. Write down the date it shows and type it in Key expires above.
    3. Repository access: Only select repositories, pick flashgrain. Permissions: Contents, Read and write. Leave the rest alone.
    4. Generate, copy the key, paste it here, tick Remember, press Load.

    Lost a phone or laptop? Delete the key on that same GitHub page and it stops working right away.
