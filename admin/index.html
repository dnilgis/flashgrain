Admin

Changes save to the site's GitHub repo and show on the site in 1–3 minutes. You need a GitHub key with write access to this one repo (see README).

Cash bids

Cash on the site = futures + your basis. Untick Show to hide a row. DTN basis is what DTN posts right now, for reference only; the site uses yours. Every save lists the price changes and asks first.

Nearby bids

Other elevators' own posted bids, shown under the cash bid table for comparison and labelled as theirs. They never change Flash Grain's prices. Untick to hide.

Hours

Alert bar

Yellow bar across the very top of the site. One message per line. Empty hides the bar.

With a date, the bar hides itself after that day. Without one, it stays until you clear it.
